Italy Standard Price

PV-only pricing model. Define how cart pallet count maps to a country standard price.

PV tier matching rule Display labels should read "Only 1 pallet", "2 to 8 pallets", and "Above 8 pallets". Backend still saves Above 8 pallets as tierMin = 9 and tierMax = empty. Kit and Battery skip this rule and use fixed country price.

PV price model definition PV only

Backend rule: if productType = PV, resolve standardPrice by the first tier where palletCount >= tierMin and tierMax is empty or palletCount <= tierMax.
